# Итоговый проект по облачным технологиям

## Описание проекта
Реализован механизм перекачки данных из S3 в Vertica напрямую, без предварительного локального скачивания. При передаче данных из Staging в DWH реализован расчёт витрины. В витрину попадают транзакции с полуночи данного дня включительно до следующей полночи невключительно.

## Выбор источника данных
В силу аварии на сервисах Yandex Cloud единственным доступным источником данных оказался S3.

## Структура репозитория
- 'src/dags/1_data_import.py' — DAG загрузки сырых данных из S3 в слой STAGING.
- 'src/dags/2_datamart_update.py' — DAG расчёта и обновления витрины в слое DWH.
- 'src/sql/' — SQL-скрипты для создания таблиц, проекций и расчёта витрины.
- 'src/py/' — (пусто, так как источником выбран S3).
